# ☕ Aroma Café

Projeto desenvolvido para fins educacionais, simulando o site institucional de uma cafeteria fictícia.

O objetivo deste projeto é praticar conceitos básicos de Git e GitHub, além de apoiar o desenvolvimento web utilizando HTML, CSS e Django.

## 📖 Sobre o Projeto

A Aroma Café é uma cafeteria fictícia criada para servir como exemplo em atividades de programação.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Django
- Git
- GitHub

## 🚀 Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/Livia-Rachell/AromaCafe.git
```

2. Acesse a pasta do projeto:

```bash
cd AromaCafe
```

3. Crie e ative o ambiente virtual:

```bash
python -m venv venv
venv/Scripts/activate
```

4. Instale as dependências:

```bash
pip install -r requirements.txt
```

5. Execute o servidor Django:

```bash
python manage.py runserver
```

6. Abra no navegador:

```text
http://127.0.0.1:8000/AromaCafe/
```

## 🤝 Atividade Colaborativa

Durante a atividade, cada participante será responsável por uma seção do site.

O objetivo é demonstrar como o Git permite que várias pessoas trabalhem simultaneamente em um mesmo projeto, registrando alterações e organizando o histórico de desenvolvimento.

## 📌 Observação

Este projeto possui finalidade exclusivamente educacional e foi desenvolvido para apoiar aulas introdutórias de Git, GitHub, HTML,CSS e Django.
